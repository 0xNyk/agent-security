# Indicators for scripts/ioc-sweep.sh. One per line: KIND<TAB>VALUE<TAB>note
# KIND:
#   PATH     a path relative to $HOME that should not exist
#   FILENAME an exact basename that should not exist anywhere under the scanned roots
#   NPMPKG   an npm package name that should not appear in any lockfile
#   WORKFLOW a token that should not appear in any .github/workflows file
#   SHELLCMD a regex (grep -E) that marks a shell-history line as a lure shape; the
#            match prints only the pattern name and host, never the command
#   ABSPATH  an absolute path that should not exist
#   REPOPATH a path suffix (dir/file) that should not exist inside any working tree
#   TMPGLOB  a directory/file glob that should not exist directly under a tmp dir
#   NPMVER   name<TAB>version: a specific compromised npm release (lockfiles, node_modules, caches)
#   PYPKG    a PyPI package name that should not be installed or locked anywhere
#   PYVER    name<TAB>version: a specific compromised PyPI release
#   CRATE    a crates.io name that should not be in any Cargo.lock or the cargo registry
#   CRATEVER name<TAB>version: a specific hijacked crate release
#   ACTIONREF owner/repo of a GitHub Action whose tags were hijacked: flagged when a
#            workflow uses it by tag/branch instead of a full commit SHA
# Blank lines and # comments are ignored. Append freely; the script re-reads on every run.
