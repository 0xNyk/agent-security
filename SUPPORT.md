# Support

Use a GitHub issue for reproducible bugs and scoped feature requests. Search open and closed issues before filing a new one.

Do not use a public issue for a detector bypass, guard bypass, credential exposure, or another vulnerability. Follow [SECURITY.md](SECURITY.md) and open a private GitHub security advisory.

Maintainers respond when capacity permits. The project has no response-time or compatibility SLA. There is no private consulting channel. Support for releases before the current minor is not promised.
