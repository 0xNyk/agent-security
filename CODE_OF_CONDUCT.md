# Code of conduct

## Expected conduct

Participate with technical honesty and respect. Critique claims, code, tests, and threat models without attacking the person behind them. Keep reports reproducible, protect private data, and give reporters credit according to their preference.

Harassment, threats, discriminatory language, deliberate exposure of private information, and attempts to pressure maintainers into publishing exploit details are not accepted.

## Scope

This policy applies to repository issues, pull requests, discussions, security reports, and project spaces managed by the maintainers.

## Enforcement

For ordinary conduct concerns, contact a maintainer privately through their GitHub profile. For a concern that includes a vulnerability or sensitive evidence, use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).

Maintainers may edit or remove content, lock a thread, reject a contribution, or temporarily or permanently restrict participation. A maintainer named in a report must not make the final enforcement decision when another maintainer is available. If no independent maintainer is available, that limitation will be disclosed to the reporter.
